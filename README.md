# DataPulse 🔍

**PS-019: Personal-Data Discovery and Privacy Evidence Inventory**

## About the Project

DataPulse is a proposed privacy-focused system designed to discover and monitor personal data across CSV files and SQL databases.

It aims to identify personal-data fields, maintain a structured inventory, flag missing purpose and retention information, and help organizations track changes in their data environment.

## Project Status

**Current Status:** Planning stage — implementation has not started yet.

Our planned development includes personal-data discovery, configurable detection rules, privacy evidence inventory, purpose and retention metadata checks, per-class precision and recall evaluation, and a dashboard for human review.

## Expected Outcome

DataPulse aims to help organizations maintain a clearer inventory of personal data, identify missing privacy documentation, and detect newly discovered personal-data fields as their data environment changes.

The system will provide technical evidence for human review rather than automatically determining legal compliance or deleting source data.
